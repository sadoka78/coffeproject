# Тёплый — демонстрация предзаказа кофе

Статический интерактивный прототип дипломного проекта: мобильный интерфейс гостя, панель бариста и предложение о пилотном сотрудничестве.

## Запуск

Откройте `index.html` в современном браузере или используйте любой локальный статический HTTP-сервер. Сборка и установка зависимостей не нужны. Интерфейс адаптируется к телефону и компьютеру. Шрифты Google Fonts необязательны: при отсутствии сети используются системные.

## Демонстрация

1. Добавьте напиток, выберите объём и молоко.
2. Оформите тестовый заказ на выбранную точку и время.
3. Откройте «Панель бариста», подтвердите, приготовьте и выдайте заказ.
4. Проверьте статус и начисленные бонусы в «Мои заказы».
5. Следующий заказ можно частично оплатить бонусами.

Отклонение требует причины и возвращает списанные бонусы. Доступность позиций меняется в панели бариста. Примерные цены указаны в тенге, география будущего проекта не определена.

Раздел «Для кофеен» содержит предложение. Кнопка сохранения в PDF открывает системную печать: выберите «Сохранить в PDF». Контакты перед рассылкой добавьте в сопроводительное письмо.

## Ограничения

Это демонстрация, не работающий сервис кофейни. Данные сохраняются только в localStorage этого браузера и синхронизируются между вкладками одного origin. Нет сервера, авторизации, настоящей оплаты, уведомлений или интеграции с кассой. Данные можно удалить через настройки сайта в браузере. Не вводите персональные данные. Бренд и точки вымышлены. Суммы и правила бонусов демонстрационные.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует только HTML, CSS и JS при обновлении `main`. В Settings → Pages должен быть выбран источник GitHub Actions. Если автоматическое включение Pages недоступно для стандартного токена workflow, администратору нужно один раз выбрать этот источник вручную.
